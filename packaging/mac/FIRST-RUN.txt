拍摄时间改名器（ShutterSort）· macOS 版
========================================

这是一个单文件 App，双击就能用，不需要装 Python、不需要碰命令行。


一、第一次打开被 macOS 拦下怎么办
--------------------------------

双击时如果弹出「无法打开，因为 Apple 无法验证此 App 是否包含可能危害
Mac 的安全内容」—— 这是正常现象。作者没买苹果的开发者签名证书
（一年 688 元），所有个人开发者的小工具都会这样。

任选一种方式放行，只需要做一次：

  【方法一，推荐】在访达里右键点 ShutterSort → 选「打开」→ 再点「打开」

  【方法二】打开「终端」，粘贴下面这行后回车：

      xattr -dr com.apple.quarantine /Applications/ShutterSort.app

  App 不在「应用程序」文件夹就换成实际路径。偷懒的办法：输入
  xattr -dr com.apple.quarantine 加一个空格，然后把 App 从访达拖进
  终端窗口，路径会自动补全。

放行之后双击就正常了，以后不会再问。


二、支持哪些 Mac
----------------

  · 仅支持 Apple 芯片：M1 / M2 / M3 / M4
  · 系统要求 macOS 11 或更高
  · 老的 Intel 芯片 Mac 用不了这个包，请改用源码方式：
    解压 Source code (zip) → 双击 start.command（需要 Python 3.8+）


三、它会做什么、不会做什么
--------------------------

会做：读取照片 / 视频里内嵌的拍摄时间（EXIF / XMP / MP4 容器元数据），
      把时间写进文件名，让你在访达里按名字排序就等于按时间排序。

不会做：
  · 不联网。本地服务只监听 127.0.0.1，打不开外网，也不上传任何数据
  · 不改文件内容。只做重命名，一个字节都不动
  · 不覆盖已有文件。重名自动加 _1 / _2
  · 关窗即退出，不会在后台常驻

每次改名都会在下面这个目录留一份记录，重启之后依然可以一键还原：

  ~/Library/Application Support/ShutterSort/rename-history


四、可选增强（不装也能正常用）
------------------------------

      brew install exiftool ffmpeg

  exiftool：元数据提取覆盖度最高（装了就自动优先用）
  ffmpeg  ：视频缩略图预览

不装的话程序会用内置解析器，功能完整，只是缩略图显示图标。


五、源码与自证
--------------

  https://github.com/js-ping/shuttersort

整个程序是纯 Python 标准库写的，没有第三方运行时依赖。源码就在 src/
里，可以自己核对，也可以自己用 packaging/build_app.command 重新打一份。
不想信这个包的话，用源码跑一遍是最踏实的做法 —— 功能完全一样。
